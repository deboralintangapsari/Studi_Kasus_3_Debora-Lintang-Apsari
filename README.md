## Tentang Program Ini
Ini program buat pinjam buku di perpustakaan Fakultas Teknik. 
Jadi kita bisa liat buku apa aja yg ada, terus bisa pinjam, hapus, sama liat buku yg udah dipinjam.

## Yang Ada di Dalam Program
1. **Tuple** → buat nyimpen daftar buku. Soalnya daftar bukunya gak bakal berubah
2. **List** → buat nyimpen buku yg dipinjam. Soalnya bisa nambah sama dihapus
3. **While** → buat ngulangin menu terus sampai kita pilih selesai
4. **If Else** → buat milih menu 1 sampai 5
5. **.lower()** → biar ngetiknya bebas. Mau "Mekanika" atau "mekanika" tetep kebaca
6. **.strip()** → biar kalo kepencet spasi gak error

## Cara Jalanin Programnya
1. Buka file `studi_kasus_3.fiks.py`
2. Run di Python
3. Masukkin nama kamu
4. Pilih menu 1-5
